# 1.5.11 — Smart Import (primeira etapa, revisão)
Resolução por UUID e índice local, tipo, edição e correspondência bilíngue. Nome isolado é somente candidato. Variantes, diferenças de schema e fontes ambíguas são preservadas, sem sobrescrever compêndios. Prévia mostra diferenças e indisponibilidade de índices. Bloqueio local de importações e auditoria após progressão; verificação de Activities nas adições.
Limitações: sem remoção automática de duplicatas (a auditoria somente leitura está disponível), mesclagem automática de variantes, trava distribuída entre navegadores ou tradução completa. JavaScript livre que chama Actor/Item diretamente pode contornar as proteções. A prévia ainda não é um simulador de combate. Testar npm test e Foundry V14/D&D5e real em dois ambientes, inclusive macro original de Ruan, antes de publicar.

- A Central oferece Revisar possíveis duplicatas: pares, IDs, origem, recursos gastos e diferenças mecânicas, sem alterar o Actor. Um Item explicitamente oficial sem dados mecânicos suficientes é bloqueado se a fonte não puder ser confirmada. Para indicar a base de um homebrew, informe jarvis.provenance.baseUuid; isso não autoriza substituir seus dados.
